# Project Requirements

## 1. Objectives

The main objectives of the Student Academic Record Management System are:

- To store student details in an organized way.
- To enter and manage student marks.
- To calculate total marks and percentage.
- To display the student's pass or fail result.
- To search for student records.
- To display all student records.
- To calculate basic class statistics.
- To demonstrate basic Python programming concepts.

## 2. Functional Requirements

### Student Management

The system should allow the user to enter:

- Student ID
- Student Name
- Branch

### Marks Management

The system should allow the user to enter marks for:

- Python
- Mathematics
- English

### Result Management

The system should:

- Calculate total marks.
- Calculate percentage.
- Display PASS or FAIL.

### Search

The system should allow the user to search for a student using the Student ID.

### Display Records

The system should display the details of all students stored during the program execution.

### Class Statistics

The system should display:

- Total number of students.
- Class average when marks are available.

## 3. Non-Functional Requirements

### Usability

The system should have a simple menu-based interface that is easy to understand.

### Reliability

The system should display appropriate messages when a student is not found or marks have not been entered.

### Maintainability

The program is divided into separate Python modules so that different functions can be managed separately.

### Error Handling

The system should handle invalid menu choices and provide suitable messages to the user.

## 4. Input

The system accepts:

- Student ID
- Student Name
- Branch
- Subject marks
- Menu choice

## 5. Output

The system displays:

- Student details
- Entered marks
- Total marks
- Percentage
- Pass/Fail result
- Class statistics
- Appropriate error messages
