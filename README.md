# Student Academic Record Management System

## Overview

Student Academic Record Management System is a simple Python-based project used to manage student academic information.

The system allows the user to add student details, enter marks, calculate results, search for students, display all students, and view class statistics.

The project is developed using basic Python programming concepts such as variables, input/output, lists, dictionaries, conditional statements, loops, functions, and modules.

## Features

- Add student details
- Enter marks for students
- Calculate total marks and percentage
- Display pass or fail result
- Search for a student
- Display all students
- Show class statistics
- Simple menu-based interface

## Project Files

- `main.py` - Main program and menu
- `student.py` - Adds student details
- `marks.py` - Enters student marks
- `result.py` - Calculates student result
- `search.py` - Searches for student details
- `statistics.py` - Displays class statistics
- `README.md` - Project documentation

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `main.py`.
3. Run the program using `Ctrl + F5`.
4. Select an option from the menu.
5. Enter the required student information.
